 Slide 1: HCI Focus — Interaction & UI Elements

Three HCI elements identified in Google Earth:

1.Search Bar — Enables quick location lookup with autocomplete and geocoding support.
2. Navigation Controls (Zoom & Compass) — Provides intuitive orbit controls and orientation feedback for 3D navigation.
3. Layers Panel— Allows users to toggle data layers (Satellite, 3D Buildings, Terrain, etc.) to control visual complexity.


Slide 2: CG Focus — Rendering & Visual Elements

Three CG elements identified in Google Earth:

1.3D Mesh Geometry — Polygonal structures (vertices, edges, faces) that define the shape and volume of buildings and terrain.
2.Texture Mapping & Material— High-resolution satellite imagery mapped onto 3D surfaces to create realistic appearances.
3. Lighting & Shadow Rendering Directional lighting that simulates sunlight and casts dynamic shadows for depth perception.



Reflection Questions

Q1. How does Computer Graphics quality help or hinder the user's ability to interact with the software?**

High-quality CG enhances spatial understanding through realistic lighting, textures, and 3D meshes. However, excessive rendering demands can cause lag and frame drops on lower-end devices, hindering smooth interaction.

Q2. What is one simple HCI change you would make to improve the user interface?**

Add a "Quick Tour" onboarding button for first-time users that demonstrates basic 3D gestures (drag, zoom, pan) with animated hints, reducing the learning curve and improving usability.
